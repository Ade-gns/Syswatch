Contrôles de base : boutons, bouton segmenté, interrupteur, curseur, champ, case, pastilles de couleur, badges d'état, jauges et touches de clavier.

Bordure de contrôle `control-border` (3:1). Anneau de focus de 2 px en accent. Le bouton primaire utilise `on-accent`, à recalculer si l'accent change. Les badges d'état portent toujours un mot.
