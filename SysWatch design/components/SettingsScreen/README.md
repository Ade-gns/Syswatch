Maquette de la page Paramètres : thème clair/sombre, couleur d'accent avec préréglages, widget compact, mode jeu et réglages généraux.

Elle est interactive : changer le thème ou la couleur recolore toute la fenêtre. Les cinq préréglages (cyan, vert, orange, rose, violet) ont une valeur sombre et une valeur claire. Une couleur libre recalcule `--on-accent` pour garder un texte lisible. Les alertes (`warn`, `crit`) ne changent jamais.
