Graphique en courbes temps réel sur 60 secondes, avec survol détaillé et échelle fixe ou automatique.

Le consommateur fournit une série par courbe (nom, couleur, valeur de base) ou ses propres échantillons. Trait plein pour la première courbe, tirets longs pour la deuxième, pointillés pour la troisième. Au survol, la bulle liste toutes les séries à l'instant visé et le graphique se fige. Il se fige aussi si l'utilisateur demande moins d'animation.
