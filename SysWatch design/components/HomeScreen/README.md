Maquette de la page Accueil en mode normal : quatre cartes de métrique, graphique temps réel, réseau, top processus, températures et alertes récentes.

À utiliser comme référence de composition d'une page à grille de widgets. Les cartes de métrique prennent 3 colonnes (128 px), le graphique 8 colonnes, les cartes de liste 4 colonnes. Montre les trois niveaux de seuil : mémoire à 82 % (attention) et disque à 91 % (critique). Le consommateur fournit les mesures ; le graphique avance d'un point par seconde.
